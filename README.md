# マクロ経済学 演習サイト

創価大学 マクロ経済学／ERE対策。GitHub Pages で配布します。

## ファイル構成

```
（リポジトリのルート）
├── index.html      演習本体（講義回別・分野別・模試・公式シート）
├── questions.js    問題バンク ← 問題の追加・修正はここだけ
├── shooting.html   マクロ シューティング（出題範囲を選べます）
├── typing.html     タイピング だいぼうけん（そのまま）
└── README.md       このファイル
```

すべて同じ階層に置いてください。相対パスで参照し合っているので、
サブフォルダに入れるとリンクが切れます。

外部のライブラリ、CDN、画像ファイルは一切使っていません。
タイピングゲームの裏ボス画像も HTML の中に埋め込まれているので、
画像ファイルを別途アップロードする必要はありません。

## GitHub Pages の公開手順

1. GitHub で新しいリポジトリを作る（Public）
2. 上の4ファイル＋README.md をアップロード（Add file → Upload files）
3. Settings → Pages → Source を「Deploy from a branch」、
   Branch を `main` / `(root)` にして Save
4. 1〜2分待つと `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます

`index.html` がルートにあるので、トップページが演習画面になります。

## 問題を追加するとき

`questions.js` の `BANK` 配列に1件足すだけです。
index.html もシューティングも同じファイルを読むので、両方に同時に反映されます。

```javascript
{
  id:"islm-11",          // 重複しない識別子
  tag:"islm",            // 分野（nipa / k45 / islm）
  lec:"L02",             // 講義回（任意。省略可）
  level:"B",             // A=基礎 B=標準 C=応用
  type:"static",         // static=固定 / gen=数値自動生成
  stem:"問題文",
  choices:["選択肢1","選択肢2","選択肢3","選択肢4"],
  answer:0,              // 正解の位置（0から数える）。出題時に自動でシャッフルされます
  explain:"解説",
  why:["", "肢2が誤りの理由", "肢3が誤りの理由", "肢4が誤りの理由"]
}
```

新しい分野を足すときは `TAGS` に、新しい講義回を足すときは `LECTURES` に
1行追加してください。ホーム画面のカードも、シューティングの出題範囲も、
自動でその項目が増えます。

## 気をつけること

- **Service Worker は入れていません。** オフライン対応にすると、問題を追加しても
  学生の端末に古い `questions.js` が残り続けることがあるためです。
- 学習の進捗は学生のブラウザの中だけに保存されます。教員側には送信されません。
- 更新が反映されないときは、学生に「再読み込み」（スマホなら一度タブを閉じる）を
  案内してください。

## ライセンスと出典

問題文・選択肢・解説はすべて本教材のための書き下ろしです。
過去問を追加する場合は、出所ごとに扱いが異なるので注意してください。
